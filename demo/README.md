# demo/ — 盛岡花火3D見え方シミュレーター（デモ版）

> **⚠️ これはデモ版です。**
> 座標・評価値・混雑予測は**デモ用の概算値および仮の設定値**であり、公式に確認された値ではありません。
> 実際の見え方・混雑・安全を保証するものではありません。

## 公開URL（GitHub Pages）

<https://teruemon325.github.io/claude-firework/>

`.github/workflows/pages.yml` により、`demo/` 配下を更新して push すると自動で再公開されます。
初回のみ、リポジトリの **Settings → Pages → Source** を **「GitHub Actions」** に設定する必要があります。

デモ版のため、`index.html` に `noindex, nofollow` を指定して検索エンジンには載らないようにしています。

## 実行方法（ローカル）

ビルド不要です。npm / Vite / React は使わず、CesiumJS を CDN（**バージョン 1.117 固定**）から読み込みます。
ES モジュールを使うため、**ローカル HTTP サーバー経由**で開いてください。

```bash
# リポジトリのルートで
python3 -m http.server 8080
#   Windows: py -3 -m http.server 8080
#   PHP:     php -S localhost:8080

# ブラウザで
# http://localhost:8080/demo/index.html
```

Cesium ion のアカウント・トークンは**不要**です（地形は直接配信 URL から取得）。

## 実装している機能

| 機能 | 内容 |
|---|---|
| 3D 都市モデル | PLATEAU 建築物モデル（LOD1 / LOD2 切替）＋ PLATEAU-Terrain |
| 花火の表示 | 打上地点（推定）に地上高 50〜300m で表示。高度スライダー |
| 観覧候補地点のランキング | 設定ファイルに登録した候補だけを 100 点満点で評価し、順位・内訳・理由・注意事項を表示 |
| 交通規制 | 公表内容を基に再作図した GeoJSON を**赤色**で表示。規制時間・都南大橋の全面通行禁止時間・対象年度を常時表示 |
| 混雑予測 / 渋滞予測 | 時間帯を選び、低い / 中程度 / 高い の 3 段階と**予測の根拠**を表示 |
| 視点移動 | 候補地点をクリックすると、目線 1.6m の高さから花火の方向を向く |
| 昼夜切替 | 時刻とライティングを切り替え |
| 出典・免責 | 初回モーダルと画面下部に常時表示 |

```

├── data/

└── js/
    ├── config.js       候補地点・打上地点・時間帯・配点などの設定（★ここを編集）
    ├── geo.js          測地計算（Cesium 非依存の純関数）
    ├── scoring.js      候補地点の評価（Cesium 非依存）
    ├── congestion.js   混雑・渋滞予測（Cesium 非依存）
```

## 評価の配点（合計 100 点）

| 項目 | 配点 | 見ているもの |
|---|---|---|
| 花火の見えやすさ | 40 | 打上地点までの距離帯 × 遮蔽の想定（設定値）× 高低差の想定 |
| 打上地点からの距離 | 20 | 近すぎず遠すぎない帯（およそ 800m〜2.5km）を高く評価 |
| 交通規制の影響 | 15 | 規制区間（GeoJSON）までの最短距離 |
| 混雑予測 | 15 | 下記の混雑予測の結果 |
| アクセス | 10 | 設定ファイルの `accessScore` |

## 混雑予測・渋滞予測の考え方

**リアルタイム情報ではありません。**次の 4 つから 3 段階で算出します。

1. 会場（打上地点）までの距離
2. 交通規制区間との位置関係
3. 駅・特設駐車場・会場出入口（`HUBS`）との距離
4. 時間帯（開場前 / 打上直前 / 打上中 / 終了直後 / 規制解除ごろ）

終了直後がもっとも高く、打上中はいったん下がる、という想定です。
根拠は画面にそのまま表示されます。

## 候補地点を追加・修正するには

`demo/js/config.js` の `CANDIDATES` を編集します。

```js
{
  id: 'c6',
  name: '地点の名称',
  lon: 141.xxxxxx, lat: 39.xxxxxx,
  kind: '都市公園',            // 地点種別
  isPublic: true,              // 公共の場所かどうか
  obstruction: 'medium',       // low | medium | high（遮蔽の想定）
  elevationAdvantage: 0,       // 0=平地 1=やや高い 2=高台
  accessScore: 7,              // 0〜10
  accessNote: 'アクセス情報',
  cautions: ['注意事項', '…'],
  source: '情報源',
  checkedAt: '2026-08-20',     // 確認日
}
```

### ★ 登録してはいけない場所

- **私有地**
- **立入禁止区域**
- **河川管理用道路**（規制対象であり、GeoJSON にも通行止めとして入っています）
- **危険箇所**（堤防の斜面、線路周辺、路肩、見通しの悪い道路など）

### ★ 表現のルール

- 「必ず見える」「安全」「公式の穴場」といった**断定をしない**
- 「見える可能性があります」「表示されている範囲では遮るものがありません」のように書く
- 「おすすめ」「穴場」といった**行動を誘導する語を避ける**

## 既知の制約

- 座標はすべて**デモ用の概算値**です。公開前に地理院地図等で実測して置き換えてください。
- 打上地点は公表されていないため**推定値**です。
- 評価は建物の**遮蔽を実際に計算していません**（設定値による想定）。3D 上での遮蔽判定は未実装です。
- 樹木・電線・看板・仮設物・当日の人や車・煙・天候は再現していません。
- 建物データは 2024 年度整備ですが、**調査年は 2018 年**など、より古い場合があります。
- 建物の高さは点群の中央値に基づく簡略化で、**実際の建物はモデルより高い場合があります**。
- 交通規制は公表内容を基にした**概略の再作図**です。公式の図は転載していません。
- Phase 1 では React + TypeScript + Vite への移植を想定しています（`docs/02-architecture-and-plan.md`）。
