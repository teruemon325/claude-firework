# 03. 必要データ・ライセンス・画面表示する文案

## 1. 必要データ一覧

| # | データ | 取得元 | 形式 | 取得方法 | 必須 |
|---|---|---|---|---|---|
| 1 | 盛岡市 建築物モデル | PLATEAU 配信サービス | 3D Tiles 1.0 | カタログ API で URL 取得 → `Cesium3DTileset.fromUrl` | ◎ |
| 2 | 地形 | PLATEAU-Terrain **直接配信**（Cesium ion 非経由） | quantized-mesh-1.0 | `CesiumTerrainProvider.fromUrl('https://tile.plateauview.mlit.go.jp/terrain/layer.json')` | ◎ |
| 3 | 打上地点の座標 | 主催者発表＋地理院地図で目視推定 | JSON（自作） | `public/data/launch-site.json` | ◎ |

| 5 | 航空写真オルソ | PLATEAU-Ortho | ラスタタイル | `UrlTemplateImageryProvider`<br>`https://api.plateauview.mlit.go.jp/tiles/plateau-ortho-2023/{z}/{x}/{y}.png` | ○（昼モードの見やすさ向上） |

◎＝必須 / ○＝あると良い / △＝任意

### 打上地点 JSON の形（例）

```json
{
  "name": "盛岡花火の祭典 打上地点（推定）",
  "lon": 0.0,
  "lat": 0.0,
  "isEstimated": true,
  "basis": "主催者発表『都南大橋下流の北上川河川敷』を基に地理院地図で推定",
  "updatedAt": "2026-XX-XX",
  "officialUrl": "https://www.ccimorioka.or.jp/hanabi/"
}
```

> 座標は**必ず実測して埋める**こと。ダミー値のままリリースしない。

## 2. ライセンスと出典表記

### 2.1 確認すべきこと（実装前）

- G空間情報センターの盛岡市データセットページで、**適用ライセンス**（公共データ利用規約 第1.0版 /
  CC BY 4.0 / ODC BY / ODbL のいずれか）と**整備年度**を確認する。
- PLATEAU サイトポリシー（`https://www.mlit.go.jp/plateau/site-policy/`）を確認する。
- 交通規制図は**オープンデータではない**。図の転載はせず、公表内容を基に自分で作図する。

### 2.2 画面に常時表示する出典表記（文案）

```
【出典】
・3D都市モデル：国土交通省 Project PLATEAU「3D都市モデル（盛岡市）」（<採用年度>年度整備）を加工して作成
　https://www.geospatial.jp/ckan/dataset/plateau-03201-morioka-shi-<採用年度>
・地形データ：PLATEAU-Terrain
　PLATEAU | Mapterhorn | 国土地理院
　（公式指定の帰属表示。地図画面上に必ず表示すること）
・航空写真：国土交通省 Project PLATEAU「PLATEAU-Ortho（2023年度）」
・交通規制：盛岡花火の祭典実行委員会 公表資料（20XX年発表）を基に作成した概略図
　最新情報は主催者公式サイトをご確認ください https://www.ccimorioka.or.jp/hanabi/

本アプリは国土交通省・盛岡市・主催者とは関係のない非公式の参考ツールです。
```

- `<採用年度>` は **Phase 0 で決定した採用年度＝2024 年度**（確定済み）に置き換える。
- ⚠️ **整備年度（2024）と建物の調査年（実測例では 2018）は別物**。
  出典表記には整備年度を書き、免責文には調査年が古い場合があることを書き分ける。
  PLATEAU VIEW の属性パネルで個別建物の `調査年` を確認できる。
  ハードコードせず `config/attribution.ts` に置き、データセット URL の末尾年も合わせる。
- **地形の帰属表示は `PLATEAU | Mapterhorn | 国土地理院`**（公式 docs サイト「4. 帰属表示」、2026-08-20 確認）。
  **地図画面上に必ず表示**する必要があり、フッターやモーダルの中だけでは要件を満たさない可能性がある。
  → `AttributionBar` を地図の上に重ねて常時表示する設計にする。
- `/terrain/layer.json` のレスポンスにも同等の `attribution` 文字列が含まれるため、
  **ハードコードせずレスポンスから読み取って表示する**のが望ましい。
- ⚠️ 旧記述「地形データは、測量法に基づく国土地理院長承認（使用）R3JHs 778 を得て使用」は
  GitHub 旧チュートリアルの文言。GitHub 側は更新停止と明記されているため**採用しない**。
- ライセンスが CC BY 4.0 の場合は、ライセンス名とリンクも併記する。

### 2.3 表示場所

## 3. 画面に表示する免責・注意（文案）

### 3.1 初回起動時のモーダル（同意ボタンで閉じる、以後は下部に小さく常時表示）

```
このアプリについて（必ずお読みください）

・本アプリは、3D都市モデル（PLATEAU）と地形データを使って、
　花火の「おおよその見え方」を考えるための参考ツールです。
・特定の場所から花火が「必ず見える」ことを示すものではありません。
・次のものは再現していません：河川敷の草木・樹木・電柱・電線・看板・仮設物・
　工事中の構造物・当日の人や車・煙・靄・雲・天候・光害。
　これらにより、実際には見えない場合があります。
・とくに花火会場の河川敷は、モデル上では何も無い開けた空間として表示されますが、
　実際には草木や当日の仮設物・観覧者・車両があります。
　モデル上で開けて見えても、実際には遮るものがある場合があります。
・盛岡市の植生データは「単独木」のみで、面的な草地・茂みは含まれません。
　会場周辺では単独木も確認できなかったため、樹木は表示されません。
・建物の高さは、点群の中央値をもとに簡略化されています。屋根の棟・塔屋・
　屋上の設備などは表示されておらず、実際の建物はモデルより高い場合があります。
・花火のアニメーションは演出です。実際の花火の大きさ・明るさ・開き方・色・
　残光・打上の間隔や発数・打ち上がる位置を再現するものではありません。
　動きが付いても、見え方の正確さは上がりません。
・建築物データは 2024年度に整備されたものですが、建物の調査年は 2018年など
　より古い場合があります。以降の新築・解体・増改築は反映されていません。
・建築物は箱型に簡略化されたモデル（LOD1）の場合があり、建物による概略的な見え方の確認に留まります。
・地形は 5mメッシュの標高モデルに基づくため、河川敷・堤防などでは数メートルの誤差があります。
・打上地点の座標は公表されていないため、公表情報を基にした推定値です。
・表示している場所が、立ち入り可能な場所・観覧可能な場所であることを保証しません。
　私有地・立入禁止区域・河川区域・交通規制区域には立ち入らないでください。
・交通規制の表示は概略です。最新かつ正確な情報は主催者の公式発表をご確認ください。
・観覧の際は、主催者・警察・道路管理者・河川管理者の指示に必ず従ってください。

［出典・ライセンスを見る］　［理解しました］
```

### 3.2 常時表示（画面下部・1 行）

```
参考ツールです。見えることを保証しません／樹木・煙・天候等は未再現／建物データ：2024年度整備（調査年は2018年等）
```

### 3.3 観覧地点を指定したときに出す注意（毎回）

```
この地点が立ち入り可能かどうかは判定していません。私有地・立入禁止区域の可能性があります。
```

### 3.4 UI 上の用語ルール

| 使う言葉 | 使わない言葉 |
|---|---|
| 「見える可能性があります」「遮るものは表示されていません」 | 「見えます」「見えません」「おすすめスポット」 |
| 「参考値」「推定」「概略」 | 「正確な」「保証」 |
| 「観覧地点の候補」 | 「穴場スポット」 |

## 4. 交通規制 GeoJSON の作り方（Phase 6）

1. 主催者公式サイトの交通規制の**発表内容（文章・図）**を確認する。
2. 規制区間の起終点（交差点名など）を読み取り、地理院地図等でその区間の線を自分で描く。
   - 例：「盛岡南IC入口交差点〜国道396号 都南大橋東袂交差点」「ふれあいランド岩手前通り」
   - 河川管理用道路の規制は別プロパティ（時間帯が異なる）にする。
3. 各フィーチャに次のプロパティを付ける。

```json
{
  "type": "Feature",
  "properties": {
    "name": "盛岡南IC入口交差点〜都南大橋東袂交差点",
    "kind": "vehicle_closed",
    "timeRange": "18:00-21:30",
    "source": "盛岡花火の祭典実行委員会 公表資料",
    "published": "2026",
    "officialUrl": "https://www.ccimorioka.or.jp/hanabi/",
    "note": "公表内容を基に作成した概略。正確な範囲は公式発表を参照"
  },
  "geometry": { "type": "LineString", "coordinates": [] }
}
```

4. ファイル名に年を入れ（`traffic-regulation-2026.geojson`）、**年度が変わったら差し替える**運用にする。
   UI には `published` の年を必ず表示し、古い場合は警告を出す。
