## A. 盛岡市の 3D 都市モデルを特定する（**2024 年度版を最優先で確認**）

盛岡市の市区町村コードは **`03201`**。

> **重要：整備年度の優先順位**
> 1. **2024 年度版（最優先）** — あればこれを採用する
> 2. 2023 年度版
> 3. 2022 年度版（前回調査で存在を確認した版。**フォールバック**）

## B. 都南大橋周辺の収録範囲を**地物型ごとに個別確認**する（最重要）

> **注意：地物型ごとに整備範囲は異なります。**
> 「地形・道路・土地利用は 2 次／3 次メッシュ単位だから都南地区も確実に含まれる」といった
> **推定で済ませてはいけません**。メッシュ単位で整備される地物型であっても、
> 整備対象メッシュの選定範囲、年度ごとの整備方針、市域内の一部のみの整備など、
> 都南大橋周辺が含まれない可能性は残ります。**4 つとも個別に、実データで確認してください。**

### B-1. 確認の手順（各地物型に共通）

1. まず確認対象の位置を決める。**都南大橋の下流側・北上川河川敷（花火会場）の座標**と、
   そこから半径 1km・3km の範囲。
2. 次のいずれかで実データを見る。
   - **PLATEAU VIEW**（`https://www.plateau-view.mlit.go.jp/`）でデータカタログから盛岡市の
     各モデルを ON にし、当該範囲へカメラを移動して**目視**する（最も速い）。
   - カタログ API で得た URL を CesiumJS / MapLibre に読ませて目視する。
   - G空間情報センターの盛岡市データセットページに**整備範囲図**があれば併読する。
   - CityGML をダウンロードし、収録メッシュ番号から範囲を判定する
     （会場付近の 2 次メッシュ・3 次メッシュ番号を地理院の対照表で確認して照合）。
3. 「あり／なし」だけでなく、**どこまで（境界）**を記録する。

## F. 昼夜切替に必要なライティング設定の確認

> **時計（`viewer.clock`）の時刻を変えるだけでは、昼夜の見た目は十分に変わりません。**
> Cesium では**ライティングを明示的に有効化・調整する必要**があります。
> Phase 5 で作り込む前に、最小 HTML で「効く／効かない」を確認しておきます。

確認する設定項目：

| 設定 | 目的 | 確認 |
|---|---|---|
| `viewer.scene.globe.enableLighting = true` | 太陽位置に応じて地表を陰影づける（**既定は false**。これを入れないと夜でも地表が明るいまま） | [ ] |
| `viewer.clock.currentTime`（+ `shouldAnimate`） | 太陽位置を決める時刻。JST → UTC 変換に注意 | [ ] |
| `viewer.scene.globe.dynamicAtmosphereLighting` / `atmosphereLighting` 系 | 大気の明るさを時刻に追従させる | [ ] |
| `viewer.scene.skyAtmosphere`（`show` / 明るさ） | 空の色。夜は暗くする | [ ] |
| `viewer.scene.sun` / `viewer.scene.moon` | 太陽・月の表示 | [ ] |
| `viewer.scene.light`（`SunLight` / `DirectionalLight`） | 3D Tiles（建物）への当たり方 | [ ] |
| `imageryLayer.brightness` / `gamma` | 夜モードで地表テクスチャを落とす | [ ] |
| 3D Tiles の `Cesium3DTileStyle`（`color`） | 夜モードで建物を暗くする | [ ] |
| `PostProcessStageLibrary.createBloomStage()` | 花火の発光表現（**負荷が高い**。ON/OFF を設定可能にする） | [ ] |
| `viewer.shadows` / `tileset.shadows` | 影の描画（負荷とのトレードオフ） | [ ] |

### 補足：この判定の考え方

- **1〜7 は「作っても意味がない／土台が壊れている」ことを防ぐための必須条件**です。
  特に 5（高さ整合）は、後から直すとアプリ全体の座標計算をやり直すことになるため、
  ここで必ず決着させます。
- **8・10 は「開発は進めてよいが、公開してはいけない」条件**です。
  権限設定と出典表記が未了のまま公開すると、課金リスクとライセンス違反につながります。
- **3 が NO-GO ではなく条件付き GO** なのは、建物が無くても
  「地形と遠方の建物による概略的な見え方の確認」というツールとしては成立するためです。
  ただしその場合は、**何が表示されていないのかを画面に明示**することが着手の条件です。
