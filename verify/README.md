# verify/ — Phase 0 の検証用ファイル

> **ここはアプリのコードではありません。** Phase 0（実装着手前の確認）で、
> 実データを自分の目で確かめるためだけの使い捨ての検証ページです。
> Phase 1 のソース（`src/`）とは分離しています。

## 目的

**高さ整合の目視確認**（`docs/05-verification-checklist.md` の D、GO/NO-GO 項目 5・6）

PLATEAU-Terrain（Cesium ion 非経由の直接配信）と PLATEAU の建築物 3D Tiles を、
**補正を一切かけずにそのまま重ね**、都南大橋周辺で

- 建物の足元が地面に接しているか（浮いていないか／沈んでいないか）
- Cesium 上の地表標高が地理院地図の値と大きく矛盾しないか

を確認します。

**やらないこと**：花火の表示／観覧地点の選択／距離・方位の計算／交通規制の表示／
建物の高さ補正・位置補正（`modelMatrix` によるオフセット等）。

## 構成

| ファイル | 内容 | Git |
|---|---|---|
| `height-alignment.html` | 検証ページ本体。CesiumJS を CDN から読み込む単体 HTML | コミットする |
| `config.example.js` | 設定の例。**トークン等は書かない** | コミットする |
| `config.local.js` | 実際に使う設定。`config.example.js` からコピーして作る | **コミットしない**（`.gitignore` 済み） |
| `README.md` | この文書 | コミットする |

- npm / Vite / React は使いません。**CesiumJS は CDN から読み込み、バージョンは `1.117` に固定**しています。
- Cesium ion のトークンは**不要**です。地形は直接配信 URL から取得します。

## 実行手順

### 1. 設定ファイルを作る

```bash
cp verify/config.example.js verify/config.local.js
```

`verify/config.local.js` を開き、少なくとも次を自分の内容に書き換えてください。

- `meta.checkedAt` … 確認を実施する日
- `meta.checkedBy` … 確認者（任意）
- `cameras[]` の座標 … **⚠️ 初期値は都南大橋の「推定座標」です。正確ではありません。**
  ページ左下にカメラ座標が出るので、実際に都南大橋の上へ移動して読み取り、
  「この位置をコピー」ボタンで得た行に差し替えてください。

### 2. ローカル HTTP サーバーを起動する

`file://` で直接開くと、CDN のワーカー読み込みや CORS で失敗します。**必ず HTTP で開いてください。**

リポジトリのルートで、いずれか 1 つを実行します。

```bash
# Python 3（多くの環境で追加インストール不要）
python3 -m http.server 8080

# Python 3（Windows で python3 が無い場合）
py -3 -m http.server 8080

# PHP がある場合
php -S localhost:8080
```

### 3. ブラウザで開く

```
http://localhost:8080/verify/height-alignment.html
```

WebGL2 が有効な最近のブラウザ（Chrome / Edge / Firefox / Safari）で開いてください。

### 4. 終了

サーバーを起動したターミナルで `Ctrl + C`。

## 画面の見かた

| 位置 | 内容 |
|---|---|
| 左上 | カメラ位置のプリセット、建築物モデル（LOD1 / LOD2）の切替 |
| 右上 | 記録用の情報（確認日・データ年度・tileset URL・地形 URL・CesiumJS バージョン・読み込み状態）と「記録用テキストをコピー」ボタン |
| 左下 | 現在のカメラ座標。「この位置をコピー」で `config.local.js` の `cameras[]` に貼れる形式になります |
| 下部の黒帯 | 帰属表示（**必須**）。`PLATEAU \| Mapterhorn \| 国土地理院` と PLATEAU の出典 |
| 中央（赤） | 読み込みエラー。地形または建築物の取得に失敗すると表示されます |

視点を傾けるには**右ドラッグ**または **Ctrl + 左ドラッグ**です。

## 確認する項目

1. **地形が表示されるか** — 右上の「地形の状態」が ✅ になり、起伏が見えること
2. **建築物が表示されるか** — 「建築物の状態」が ✅ になること
3. **★ 建物の足元が地面に接しているか** — カメラプリセット「④ 低高度（足元確認）」で、
   建物が宙に浮いていないか、地面に埋まっていないかを見る
4. **LOD1 と LOD2 で違いがあるか** — 建築物モデルの切替ボタンで比較する
   （`docs/05` の B-2 行 2「LOD2 の整備範囲」もここで確認できます）
5. **標高の妥当性** — 都南大橋付近にカメラを寄せ、地表付近の高さを地理院地図の標高値と比べる

### ずれていた場合

**この段階では補正を入れないでください。** まず「どちらに」「何メートル」ずれているかを実測し、
`docs/05-verification-checklist.md` の D に記録します。原因の切り分けと対処方針を決めるのは、
記録したあとです（`docs/04-risks.md` の R1）。

## 結果の記録

1. 上記 1〜5 を確認する
2. **スクリーンショットを撮る**（少なくとも「④ 低高度」の 1 枚。LOD1 と LOD2 の比較があればなお良い）
3. 右上の「**記録用テキストをコピー**」を押す
4. コピーした表を `docs/05-verification-checklist.md` の **D 節**に貼り、
   判定（接している／浮いている／沈んでいる）と実測値を書き込む
5. スクリーンショットは `docs/images/` に置き、D 節から参照する

## 注意

- PLATEAU 配信サービスは**公式に「試験的な運用であり、提供期間やサービスレベルは保証しない」**と
  されています。URL の変更や停止があり得ます。エラーが出た場合は、まず
  `docs/05-verification-checklist.md` の A・C に記録した URL をブラウザで直接開いて疎通を確認してください。
- `config.local.js` に**トークンや秘密情報を書いてもコミットされません**が、
  フロントエンドに書いた値は**ブラウザから読み取れます**。秘密にはできない前提で扱ってください。
- CesiumJS のバージョンを変える場合は、`height-alignment.html` の 3 か所
  （`widgets.css` / `Cesium.js` / `data-cesium-version`）と `config.local.js` の
  `meta.cesiumVersion` をすべて合わせてください。不一致の場合は画面にエラーが出ます。
