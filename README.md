# 盛岡花火3D見え方シミュレーター（調査・計画フェーズ）

盛岡市の PLATEAU 3D都市モデルを使い、**都南大橋下流・北上川河川敷**で打ち上げられる花火が
市内の各地点からどのように見えるかを、ブラウザ上で 3D 表示して確かめるための Web アプリです。

> **現在のステータス：Phase 0（実データ確認）を進行中。あわせて `demo/` にデモ版を実装しています。**
>
> - `docs/` … 実現可能性調査の結果と段階的な実装計画、Phase 0 の実測記録
> - `verify/` … Phase 0 の検証用ページ（高さ整合の確認）
> - `demo/` … **デモ版アプリ**（ビルド不要。`python3 -m http.server` で起動）
>
> **⚠️ デモ版の座標・評価値・混雑予測は概算値および仮の設定値です。**
> 公式に確認された値ではなく、実際の見え方・混雑・安全を保証しません。

## デモ版の起動

```bash
python3 -m http.server 8080
# http://localhost:8080/demo/index.html
```

## 結論（要約）

- **技術的に実現可能**。React + TypeScript + Vite + CesiumJS + PLATEAU 配信サービス（3D Tiles / Terrain）で、
  第 1 版の機能一覧はすべて実装できる見込み。
- ただし着手前に **Phase 0（実データ確認）** が必須です（詳細は `docs/05-verification-checklist.md`）。
  1. ~~**整備年度の決定**~~ → **✅ 完了：2024 年度に確定**（配信カタログには 2024 年度のみ存在、spec 4.1）。
     建築物は **LOD1 / LOD2 の両方**があり、`latest` 指定の URL も有効。
     **地形（`dem`）はカタログに無く**、植生（`veg`）は存在することも判明
  2. **収録範囲の個別確認** — 都南大橋周辺について、**建築物 LOD1 / LOD2・植生・道路・土地利用**を
     個別に実データで確認する（メッシュ単位の地物型も推定で済ませない）。
     地形は PLATEAU-Terrain 側で判定する
  3. **地形アセットの有効性確認** — PLATEAU-Terrain のアセット ID は固定せず、
     最新公式ドキュメントまたは実アクセスで確認し、**採用 ID・確認日・確認方法を記録**する
  4. **高さ整合の実測** — 都南大橋周辺で建物が地面から浮かない／沈まないかを実測する
     （Cesium World Terrain との組み合わせは「ずれる可能性がある」前提で実測。数値は事前に断定しない）
  5. **Cesium ion トークンの安全設定** — `VITE_` 環境変数は**ブラウザに公開される**ため、
     権限（スコープ）の最小化とドメイン制限を設定する
  6. **昼夜切替のライティング確認** — 時刻を変えるだけでは見た目は変わらないため、
     `globe.enableLighting` 等の設定が効くことを事前に確認する
- Phase 1 へ進めるかは、`docs/05-verification-checklist.md` 末尾の **GO / NO-GO 判定**で決めます。
- 本アプリは **「見える／見えない」を判定するものではなく、見え方を考えるための参考ツール**として設計する。
  樹木・看板・煙・天候・仮設物・当日の人出は再現できないため、画面上に常時その旨を表示する。
- 建築物 LOD1 は箱型に簡略化されたモデルであり、**「建物による概略的な見え方の確認」** に用いる位置づけ。
  個々の建物について見える／見えないを判断できる精度ではない。
